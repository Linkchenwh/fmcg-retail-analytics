# 指标口径

## 经营与品类

- 金额：纳入主分析交易行的sales_value合计，单位美元。
- 篮数/家庭数：相应筛选下的不同basket_id/household_key，跨品类不可直接相加。
- 篮均：主分析金额/有主分析购买的不同篮数；每户篮数=不同篮数/购买家庭。
- 比较窗口：最新两个完整8周，各56个相对日；保留边界周但不将不完整周与完整周直接比较。
- 品类贡献：该品类金额/同期全部主分析金额；移除商品筛选，保留时间和家庭筛选。

金额=购买家庭×每户篮数×篮均是描述性恒等式，不证明价格或因果。商品数量单位不兼容时不跨品类计算统一单价。

## 客户与观察再购

R为参照日距离最后购买日，F为窗口内不同篮数，M为主分析金额。主窗口13周，补充窗口8周，具体窗口由SQL固定。

在活跃家庭中计算20/40/60/80离散分位点，同值同分；R越小评分越高，F/M越大评分越高。无购买家庭F/M为0，R和评分为空。分层按互斥CASE顺序产生，不将窗口重算后的标签差异称为真实迁移，也不把评分当已验证预测模型。

30天观察再购以窗口首个观察购买日为索引，分母只含索引日后可完整观察30天的家庭；分子要求后续不同日发生购买。同日多篮分开统计，跟踪不足单列。这不是新客首购留存率。

## 促销

- 含负优惠篮比例：含任一种负优惠的不同篮/全部主分析篮。正向异常与负优惠可能同篮，须按实际字段核验。
- 负优惠行金额比例：负优惠商品行销售金额/同窗主分析金额，与整篮比例不同。
- 家庭活动参与：至少一次合期核销的家庭活动对/已分配家庭活动对。
- 资格对核销覆盖：至少一次合期核销的资格对/推导资格对；TypeA逐户券集合未知时留空。
- 上下文覆盖：可匹配陈列/邮报状态的交易行/全部相应交易行；未覆盖不能填“无促销”。

券活动采用原始活动范围，不能归因到缺少关联键的某个购物篮或快消品子集。优惠字段绝对值不等于企业真实成本；缺可信无促销对照、触达和费用时不估计增量或ROI。
